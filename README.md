# WCCCD Acceptable Use Policy Framework — Review Package

Draft for internal review, October 2026. Prepared by District IT.

## Files
- `index.html` — interactive review app (single file; the Word document is embedded)
- `WCCCD_AUP_Framework_Proposal.docx` — the full proposal

## How reviewers use it
1. Open the app and enter your name at the top.
2. Follow the four steps on the Overview page.
3. Mark your position on each item under **Decisions** and add comments on any page.
4. Click **Export feedback** and send the CSV to Eric.

Comments save in your browser only until exported.

## Hosting
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. The app loads from `index.html`.
